# smite-topdown-shooter-prototype

This project is a Pygame prototype of **SMITE**, an original top-down shooter inspired by *Hotline Miami*.

Built in Python using Pygame, this project helped me strengthen my object-oriented programming skills through practical application.

Features include:
- Title screen, pause menu, game over screen, and victory screen
- Player movement and shooting
- Tile-based map
- Camera tracking
- Enemies with multiple behavioral states
- Predetermined enemy patrol paths
- Field-of-view detection
- Temporary player tracking after detection
- Music and sound effects

## Requirements

- Python 3.12
- Pygame
- pytmx
- pygame-widgets

## Project Status

This game is a prototype I plan to recreate and improve in Unity.
